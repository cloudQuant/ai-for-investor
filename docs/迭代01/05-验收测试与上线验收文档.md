## 1. 文档目的

本文档定义 `ai-for-investor` MVP 的验收测试标准、上线前检查项和发布后观察指标。

验收目标：

1. 确认 P0 功能符合 PRD 和 SRS。
2. 确认核心用户路径可用。
3. 确认安全、合规、SEO、运维和数据指标达到上线基线。
4. 确认发布后可以监控、回滚和复盘。

---

## 2. 验收范围

### 2.1 功能验收范围

1. 用户注册、邮箱验证、登录、退出、忘记密码。
2. 博客浏览、搜索、后台发布和 SEO 输出。
3. 论坛浏览、发帖、回复、举报和管理。
4. 工具列表、详情、任务创建、状态查询和结果查看。
5. GitHub 项目采集、评分、审核和周报素材池。
6. 管理后台。
7. 基础埋点和指标看板。
8. 论坛统一 UI 设计和多主题切换。

### 2.2 非功能验收范围

1. 权限和越权测试。
2. Markdown XSS 安全。
3. 登录、注册、发帖、工具任务限流。
4. 工具运行隔离、超时和资源限制。
5. 日志、指标、告警、审计。
6. 备份恢复和回滚演练。
7. sitemap、RSS、结构化数据。
8. UI 主题一致性、可访问性和 SSR 首屏主题表现。

---

## 3. 验收环境

| 环境 | 用途 | 要求 |
|---|---|---|
| local | 开发自测 | 可通过 Docker Compose 启动核心依赖 |
| test | 集成测试和产品验收 | 与生产配置接近，使用测试数据 |
| prod | 生产发布 | HTTPS、备份、监控、告警、回滚方案齐备 |

验收优先在 test 环境完成，prod 发布前执行上线检查。

## 5. 安全验收

### 5.1 认证与授权

| 编号 | 验收项 | 期望结果 | 优先级 |
|---|---|---|---|
| SEC-001 | 未登录访问写接口 | 返回 401 或登录引导 | P0 |
| SEC-002 | 普通用户访问管理接口 | 返回 403 | P0 |
| SEC-003 | 用户访问他人工具任务 | 返回 403 或 404 | P0 |
| SEC-004 | 登录暴力破解 | 连续失败 5 次后锁定 15 分钟，超过阈值后限流 | P0 |
| SEC-005 | 后台高风险操作 | 有审计日志 | P0 |
| SEC-006 | 账号枚举测试 | 登录、注册、忘记密码对不存在/已存在用户返回相同格式的模糊提示 | P0 |
| SEC-007 | 会话超时测试 | 空闲 30 分钟后 token/session 失效，需重新登录 | P0 |
| SEC-008 | 管理员二次验证 | 管理员登录必须完成邮箱验证码或 MFA 二次确认 | P0 |
| SEC-009 | 密码强度测试 | 弱密码（少于 8 位、纯数字、常见密码）被拒绝 | P0 |
| SEC-010 | Cookie 安全属性 | 认证 cookie 包含 Secure、HttpOnly、SameSite=Lax 属性 | P0 |

### 5.2 注入与 XSS

| 编号 | 验收项 | 期望结果 | 优先级 |
|---|---|---|---|
| SEC-011 | Markdown XSS 测试 | 注入 `<script>alert(1)</script>`、`<img onerror=alert(1)>`、`javascript:` 链接，脚本不执行 | P0 |
| SEC-012 | SQL 注入测试 | 在搜索、登录、注册等输入框注入 `' OR 1=1 --` 等 payload，无效且不影响数据库 | P0 |
| SEC-013 | NoSQL 注入测试 | 在涉及 MongoDB 查询的接口注入 `{"$gt":""}` 等操作符，被拒绝或忽略 | P0 |
| SEC-014 | 日志注入测试 | 用户名或搜索关键词包含 `\n` `\r` 等控制字符，日志中被转义，不产生伪造日志行 | P0 |

### 5.3 SSRF 与请求安全

| 编号 | 验收项 | 期望结果 | 优先级 |
|---|---|---|---|
| SEC-015 | SSRF 测试 | 在可输入 URL 的场景（项目推荐等）输入 `http://127.0.0.1`、`http://169.254.169.254`、`file:///etc/passwd`，全部被拒绝 | P0 |
| SEC-016 | CORS 测试 | 从非白名单域名发起跨域 API 请求，被浏览器 CORS 策略阻止 | P0 |
| SEC-017 | CSRF 测试 | 如果使用 Cookie 认证，跨站 POST 请求缺少 CSRF token 时返回 403 | P0 |

### 5.4 文件上传与内容安全

| 编号 | 验收项 | 期望结果 | 优先级 |
|---|---|---|---|
| SEC-018 | 文件上传非法类型 | 上传 `.exe`、`.sh`、`.php` 等非图片文件被拒绝 | P0 |
| SEC-019 | 文件伪装测试 | 将 `.exe` 重命名为 `.png` 上传，服务端通过 magic bytes 检测拒绝 | P0 |
| SEC-020 | 上传文件大小限制 | 超过 5MB 的文件被拒绝 | P0 |
| SEC-021 | 上传文件路径穿越 | 文件名包含 `../` 等路径穿越字符，被清洗或拒绝 | P0 |
| SEC-022 | 用户外部链接安全 | 论坛帖子中的外部链接渲染后包含 `rel="noopener noreferrer nofollow"` | P0 |

### 5.5 工具容器安全

| 编号 | 验收项 | 期望结果 | 优先级 |
|---|---|---|---|
| SEC-023 | 工具任务超时 | 被终止，不影响 Worker | P0 |
| SEC-024 | 容器非 root 运行 | 工具容器内 `whoami` 返回非 root 用户 | P0 |

### 5.6 基础设施与配置安全

| 编号 | 验收项 | 期望结果 | 优先级 |
|---|---|---|---|
| SEC-028 | 敏感配置扫描 | 仓库不包含密钥、token、生产密码 | P0 |
| SEC-029 | HTTP 安全头测试 | 生产环境响应包含 HSTS、CSP、X-Content-Type-Options、X-Frame-Options、Referrer-Policy | P0 |

| SEC-032 | OpenAPI 文档保护 | 生产环境 `/docs` 和 `/redoc` 不可公开访问 | P0 |
| SEC-033 | Redis 危险命令 | 生产 Redis 禁用 KEYS、FLUSHALL、FLUSHDB、CONFIG 命令 | P0 |
| SEC-034 | 发帖刷屏 | 超过阈值后限流 | P0 |
| SEC-035 | 错误信息泄露 | 生产环境 500 错误不返回堆栈跟踪和数据库错误详情 | P0 |
| SEC-036 | 依赖漏洞扫描 | CI 中 Dependabot/Trivy 扫描无 HIGH/CRITICAL 级别已知漏洞 | P0 |

## 7. 上线检查清单

### 7.1 产品检查

- [ ] 首页清晰表达定位。
- [ ] 博客、论坛、工具三大入口清晰。
- [ ] 论坛 UI 在默认主题下风格统一。
- [ ] 主题切换入口清晰可见。
- [ ] 注册引导自然。
- [ ] 工具区明确风险提示。
- [ ] 全站有免责声明。
