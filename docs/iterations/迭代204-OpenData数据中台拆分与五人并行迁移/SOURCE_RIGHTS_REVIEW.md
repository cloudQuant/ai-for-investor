## 目的与边界

本文记录新浪财经、东方财富、同花顺金融数据 API（Fuyao）及相关指数权利方在官方公开页面上可查到的条款和服务说明，并将公开文本、会话内用户授权声明与尚待落实的具体合同范围分开。它不是法律意见，也不判断任何具体采集、存储或分发行为是否合法。

本次仅查阅官方协议、规则及 API 文档，没有请求或收集行情、财报等业务数据，也没有核验任何账号登录后才能查看的协议、订单、报价单、API Key 权限或双方合同。页面文字可能更新；签约和启用时应重新核对对应服务的现行协议及账号实际接受的条款。

“没有找到公开许可”只表示本次核查的公开官方材料没有证明该用途获准，不证明不存在其他协议。反过来，页面公开可访问、存在 API、签发 API Key 或技术上支持下载，也不单独证明长期保存或对外再分发获准。

### 启用前应取得的书面确认

应按每个供应商、数据集及字段分别确认：

1. 是否允许计划任务、自动化 machine-to-machine 请求、全市场批量请求；请求频率、并发、配额、IP/账号限制是什么。
2. 是否允许在 OpenData 数据库长期保存、建立备份和归档；合同到期、Key 撤销或供应商终止授权后，历史数据需删除、停用还是可继续内部使用。
3. 是否允许 ai-for-investor 通过内部 OpenData REST 使用；合同中的“内部使用”包括哪些法人、服务、用户、部署环境和展示场景。
4. 原始字段、规范化字段、派生指标、聚合结果各自的保存、展示、缓存和再分发范围；外部 API 或客户使用是否需单独商业许可及标注来源。
5. 授权覆盖哪些数据源/市场/指数代码和历史范围；许可方是否具有上游交易所、指数编制方及第三方内容的授权。
6. 许可撤销、数据更正、删除要求、审计记录、SLA 与供应商变更时的处置流程。

本文所列“待确认”仅指本次公开条款证据无法核实用户声明所对应的具体合同范围，以及端点、市场/交易所、历史范围、限额等尚待细化的边界；不否定用户已声明对 AkShare 相关数据和 Fuyao 数据允许自动采集、保存及 OpenData 与 ai-for-investor 两个内部服务间使用。公开条款核查不能替代运营台账对该声明所涉具体授权范围的登记，也不能将其扩展至未明确的范围或对外、商业再分发。
