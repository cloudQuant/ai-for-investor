Key class declarations are recorded in css-key-class-comparison.txt. The versioned changes are: border-color and dark color utilities use v4 CSS variables instead of v3 rgba literals, while tokens resolve to the same slate/gray colors; v4 border utilities also set border-style via --tw-border-style, with the preflight's solid default. rounded/rounded-t retain 4px; rounded-lg/rounded-xl get explicit v3 8px/12px compatibility declarations after v4's radius tokens. v4 shadow/ring composition adds inset variables; the compatibility layer restores the existing v3 shadow values for shadow, shadow-sm, shadow-xl and hover:shadow-md. v4 space-y and divide-y target :not(:last-child) and reverse logical sides; explicit compatibility selectors restore the current v3 sibling margin/border-top behavior for the used space-y sizes and divide-y. Placeholder, default border and cursor preflight semantics are explicitly restored.

Class selector inventory: v3 has 389 selectors; v4 has 380. The nine v3-only selectors are scanner false positives in this source tree, not active template classes: bg-amber-800/50 occurs only as dark:bg-amber-800/50 (which v4 retains); bg-rose-50, border-slate-100, and text-rose-700 only occur in :deep CSS selectors; capitalize/sticky/underline occur as JS/CSS identifiers or declarations; !table and !visible have no matching source class use.
