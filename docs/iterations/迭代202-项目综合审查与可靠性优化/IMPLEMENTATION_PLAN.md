## 5. 变更与回滚约束

- 每个切片明确编辑路径；同文件不同工作包串行处理。按仓库规则由有界 worker 实现，主线程负责方案、差异复审和独立验收；文档工作不需要实现 worker。
- 安全修复不得通过关闭认证/授权、放宽类型/质量门禁或将失败状态改名为成功来通过测试。
- 数据写入相关修复先用一次性数据库。应用回滚不等于数据库回滚：预先列出 schema 向前/向后兼容窗口和备份恢复过程；不盲目执行 downgrade。
- 202 不重新批准实盘交易、真实模型付费调用、数据供应商生产采集或 196 的可信协议启用。后续确需这些动作时，在对应范围取得授权并记录独立证据。
- 验收失败保留原始日志与环境信息，标记 FAIL/INCOMPLETE；环境缺失标记 BLOCKED_ENVIRONMENT，不能以历史 PASS 替换。
