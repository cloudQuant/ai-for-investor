## 修复范围

- 后端：补齐 Parquet 依赖；修正 Python 3.10 超时和取消异常链兼容；隔离测试事件循环中的数据库连接；恢复编排测试清空前的配置缓存；通过公共 OpenAPI 合同验证路由，并保留应用中间件的顺序与响应头检查；用兼容 Python 3.10 的同步事件保留双连接并发竞争测试，覆盖异常备注和异常链两种清理失败证据；修正 MySQL 9.4 / SQLAlchemy 2.1 索引反射及最新迁移头断言。
- E2E：显式迁移一次性数据库，再引导临时管理员；每个 job 生成并屏蔽临时凭据，服务与浏览器共享本 job 的密码。包括独立浏览器和 nightly 流程。会话恢复用例按实际重试退避预算等待，保留精确请求次数和凭据检查。夜间性能探测显式迁移临时数据库，等待成功响应后计时，并清理服务线程。
- 前端：修正组件类型标注；恢复工作区导入文件输入框的 ref 绑定；折叠知识库目录时隐藏所有后代；卸载优化页时清理轮询及安全超时；丢弃停止后返回的过拟合轮询结果。补充真实 composable、store 和组件行为测试，保持覆盖率门槛。
- 历史秘密：当前运维脚本改从环境读取数据库密码；保留已审计历史指纹，并为迁移后字节相同的历史记录添加精确别名。额外一项历史密码按用户决定记录风险接受，撤销/轮换状态仍为 `NOT_CONFIRMED`，不扩大为路径级忽略。
- 文档：严格构建已验证，GitHub Pages 按用户要求启用 workflow 发布。公开地址为 <https://cloudquant.github.io/ai-for-investor/>，实际发布仍以 master 的文档工作流为准。

## 后续产品项
